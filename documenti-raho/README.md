# Documenti Raho

Contratti di booking (EN / IT) e ricevute per booking e royalties: si compilano nel browser e si scaricano in PDF.

- Online: https://rahodavide95-sketch.github.io/RHDev/documenti-raho/
- Su iPhone e iPad: apri il link in Safari, poi Condividi › Aggiungi alla schermata Home.
- I dati che inserisci (nome, codice fiscale, IBAN, firma) restano solo nel browser che usi, non su GitHub.

Per modificarlo: cambia `app.html`, poi esegui `node documenti-raho/build.js` per rigenerare `index.html`. Dettagli in `CLAUDE.md`.
